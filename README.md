## Het spel: "Guess the Word"

We kozen voor een **woordraadspel**, geïnspireerd op het klassieke Hangman.  
De speler moet een verborgen woord raden door letters te kiezen.  
Elke foute gok brengt je dichter bij een ‘game over’ — of bij een nieuw woord als je het goed hebt.

Waarom dit spel?  
Omdat het perfect is om basislogica, events en DOM-manipulatie te oefenen.  
Simpel, visueel en leerzaam.

---

##  De tutorial

Onder het spel vind je een **beginnersvriendelijke tutorial**.  
Die legt stap voor stap uit hoe je dit spel helemaal zelf kan bouwen — vanaf nul.

Wat komt aan bod:
- Welke bestanden je nodig hebt
- Hoe je een HTML-structuur opbouwt
- Styling toevoegen met CSS
- JavaScript gebruiken voor logica en interactie
- Fouten bijhouden en het spel laten reageren
- Mogelijke uitbreidingen

De uitleg is gericht op absolute beginners, met duidelijke taal en directe voorbeelden.
