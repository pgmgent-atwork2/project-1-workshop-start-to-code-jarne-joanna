    Introductie

    Welkom bij je eerste programmeerproject! In deze tutorial bouw je een compleet Hangman-spel vanaf nul. Zelfs als je nog nooit een regel code hebt geschreven: geen paniek – we leggen alles stap voor stap uit.

    Wat is Hangman? Hangman (Galgje) is een spel waarbij je een verborgen woord moet raden. Je doet dit door letters te proberen. Elke fout zorgt ervoor dat een stukje van de galg wordt getekend. Je wint als je het woord raadt vóór het poppetje compleet is.

    Wat is HTML? HTML betekent HyperText Markup Language. Zie het als het skelet van een webpagina. Met HTML geef je structuur aan je inhoud: titels, paragrafen, knoppen, afbeeldingen… allemaal via HTML-tags zoals <h1> of <p>.

    Wat is CSS? CSS staat voor Cascading Style Sheets. Als HTML het skelet is, dan is CSS de huid, kleding en stijl. CSS bepaalt kleuren, lettertypes, ruimtes, en waar alles staat.

    Wat is JavaScript? JavaScript maakt je pagina interactief. HTML zorgt voor de structuur, CSS voor het uiterlijk, en JavaScript zorgt ervoor dat dingen reageren: klikken op knoppen, controleren of je de juiste letter koos, het tonen van een win- of verliesbericht… allemaal JavaScript.

    Wat heb je nodig?

    Voor we kunnen beginnen, heb je een paar dingen nodig:

    • Een computer (Windows, Mac of Linux)
    • Een webbrowser (Chrome, Firefox, Edge of Safari)
    • Een code-editor – wij raden Visual Studio Code aan
    • 2 tot 3 uur vrije tijd
    • Een beetje geduld en nieuwsgierigheid – programmeren is als puzzels oplossen

    Je hoeft niet alles in één keer te begrijpen. Deze tutorial is gemaakt om je te begeleiden, stap voor stap. Jij kan dit.

    Stap 1: HTML - De structuur van je spel

    Wat is HTML?

    HTML (HyperText Markup Language) is de bouwsteen van elke website. Het is de taal die we gebruiken om de structuur en inhoud van een webpagina te maken.

    Basisstructuur aanmaken

    Laten we beginnen met het maken van een nieuw project:

    1. Maak een nieuwe map voor je project en noem deze "hangman-game"

    2. Open Visual Studio Code en kies "File" → "Open Folder" en selecteer je nieuwe map

    3. Maak een nieuw bestand door te klikken op "File" → "New File" en sla dit op als "index.html"

    Game Logic (scripts.js)

    Nu gaan we de code schrijven die het spel laat werken. We splitsen dit op in kleinere stukken met uitleg bij elke stap.

    Stap 1: Elementen selecteren

    Eerst moeten we de HTML-elementen selecteren die we nodig hebben: 

    // Selecting all elements

    Wat gebeurt hier?

    • We slaan deze elementen op in constante variabelen (const) zodat we ze gemakkelijk kunnen gebruiken
    • Bijvoorbeeld: displayText verwijst naar het element met de klasse "letters" waar we later de letters van het woord tonen

    Stap 2: Variabelen instellen

    Nu stellen we enkele variabelen in die we voor het spel nodig hebben: 

    // Initializing the game variables

const maxGuessCount = 6;

    Uitleg:

    • let maakt variabelen die later kunnen veranderen
    • selectedWord slaat het huidige woord op dat moet worden geraden
    • correctLetters wordt een lijst van correct geraden letters
    • wrongGuessCount houdt bij hoeveel fouten de speler heeft gemaakt
    • maxGuessCount stelt in hoeveel fouten een speler mag maken (6 in dit geval)

    Stap 3: Eindscherm tonen

    Deze functie toont het eindscherm wanneer het spel over is: 

    // Function to display the end screen when the game is over
function showGameOver(isWinner) {
  const modalImage = endGamePopup.querySelector("img");

  if (isWinner) {
    modalImage.src = "./src/images/victory.gif";
    endGamePopup.querySelector("h2").innerText = "Gefeliciteerd!";
    endGamePopup.querySelector(
      "p"
    ).innerText = `Je hebt het woord gevonden: ${selectedWord}`;
  } else {
    modalImage.src = "./src/images/lost.gif";
    endGamePopup.querySelector("h2").innerText = "Helaas!";
    endGamePopup.querySelector(
      "p"
    ).innerText = `Het juiste woord was: ${selectedWord}`;
  }

  endGamePopup.classList.add("show");
}

    Wat doet deze functie?

    • De functie showGameOver(isWinner) krijgt één parameter: isWinner (true of false)
    • Afhankelijk van of de speler heeft gewonnen, passen we de afbeelding en tekst aan
    • We voegen een CSS-klasse "show" toe aan de popup om deze zichtbaar te maken

    Stap 4: Nieuw spel starten

    Deze functie reset het spel zodat we opnieuw kunnen beginnen: 

    // Function to start a new game
const resetGame = () => {
  correctLetters = [];
  hangmanImage.src = `./src/images/hangman-0.svg`;
  wrongGuessCount = 0;
  guessesText.innerText = `${wrongGuessCount} / ${maxGuessCount}`;

  // creates the empty letter slots (spliting the word into an array of letters and mapping them to a list item)
  displayText.innerHTML = selectedWord
    .split("")
    .map(() => `<li class="letter"></li>`)
    .join("");

  // enable keyboard buttons
  keyboardContainer
    .querySelectorAll("button")
    .forEach((btn) => (btn.disabled = false));

  // hide the game modal
  endGamePopup.classList.remove("show");
};

    Uitleg:

    • correctLetters = [] - Maakt een lege lijst aan voor correct geraden letters
    • hangmanImage.src = ... - Zet de hangman afbeelding terug naar de begintoestand
    • wrongGuessCount = 0 - Reset de teller voor verkeerde gokken
    • guessesText.innerText = ... - Update de tekst die het aantal fouten toont
    • displayText.innerHTML = ... - Maakt de lege vakjes voor letters op basis van de lengte van het gekozen woord
    • We herstellen alle knoppen en verbergen de popup

    Wat betekent selectedWord.split("").map(() => `<li class="letter"></li>`)?

    1. selectedWord.split("") - Splitst het woord in een array van letters
    2. .map(() => `<li class="letter"></li>`) - Maakt voor elke letter een list-item
    3. join("") - Voegt alles weer samen tot een string die we in de HTML kunnen plaatsen

    Stap 5: Toetsenbord maken

    We maken nu het toetsenbord dat spelers gebruiken om letters te kiezen: 

    //creating a for loop to display our keyboard buttons we use the numbers 97 to 122 since these are the ASCII values for the lowercase letters a-z
for (let i = 97; i <= 122; i++) {
  //creating a button for each letter of the alphabet
  const button = document.createElement("button");
  // converts ASCII/Unicode values to their corresponding characters
  button.innerText = String.fromCharCode(i);
  //adding the button to the keyboard div
  keyboardContainer.appendChild(button);
  //adding an event listener to the button fromcharcode makes sure that we get the correct letter when we click on the button
  button.addEventListener("click", (e) =>
    startGame(e.target, String.fromCharCode(i))
  );
}

    Uitleg:

    • We maken een for-loop die loopt van 97 t/m 122 tekens (dit zijn de ASCII-codes)
    • document.createElement("button") - Maakt een nieuwe knop aan
    • String.fromCharCode(i) - Zet een ASCII-code om naar een letter (97 wordt 'a', 98 wordt 'b', enz.)
    • keyboardContainer.appendChild(button) - Voegt de knop toe aan het toetsenbord in de HTML
    • button.addEventListener(...) - Voegt een klikgebeurtenis toe die startGame() aanroept wanneer op een knop wordt geklikt

    Stap 6: Spellogica afhandelen

    Nu maken we de functie die controleert of een letter correct is: 

    //function to handle the game logic when a button on the keyboard is clicked
const startGame = (button, clickedLetter) => {
  // Check if the letter is in the word
  if (selectedWord.includes(clickedLetter)) {
    // Split word into array of letters
    const letters = selectedWord.split("");

    // Loop through each position in the word
    for (let index = 0; index < letters.length; index++) {
      if (letters[index] === clickedLetter) {
        correctLetters.push(letters[index]);
        const letterSlot = displayText.querySelectorAll("li")[index];

        // Update the display
        letterSlot.innerText = letters[index];
        letterSlot.classList.add("guessed");
      }
    }
  } else {
    // Handle wrong guess
    wrongGuessCount++;
    hangmanImage.src = `./src/images/hangman-${wrongGuessCount}.svg`;
  }
  //disable the button after it is clicked
  button.disabled = true;
  //update the guesscount
  guessesText.innerText = `${wrongGuessCount} / ${maxGuessCount}`;

  //check if the game is over
  if (wrongGuessCount === maxGuessCount) {
    showGameOver(false);
  } else if (
    selectedWord.split("").every((letter) => correctLetters.includes(letter))
  ) {
    showGameOver(true);
  }
};

    Laten we deze functie stap voor stap bekijken:

    1. Controleren of de letter in het woord zit:

      if (selectedWord.includes(clickedLetter)) {

      Dit controleert of de aangeklikte letter ergens in het woord voorkomt.

    2. Als de letter correct is:

      • We splitsen het woord in letters
      • We doorlopen elke positie in het woord om te zien waar de letter staat
      • We voegen de correcte letter toe aan onze lijst
      • We tonen de letter op de juiste plek(ken) in het woord

    3. Als de letter niet in het woord zit:

      wrongGuessCount++;
hangmanImage.src = `./src/images/hangman-${wrongGuessCount}.svg`;

      We verhogen de foutteller en updaten de afbeelding van de hangman.

    4. Na elke letter:

      • We schakelen de knop uit zodat dezelfde letter niet twee keer kan worden gekozen
      • We updaten de tekst die het aantal fouten toont

    5. Controleren of het spel is afgelopen:

      if (wrongGuessCount === maxGuessCount) {
  showGameOver(false);
} else if (
  selectedWord.split("").every((letter) => correctLetters.includes(letter))
) {
  showGameOver(true);
}

      We controleren of:

      • De speler het maximaal aantal fouten heeft gemaakt (verloren)
      • De speler alle letters in het woord heeft geraden (gewonnen)

    De every() functie controleert of elke letter in het woord voorkomt in onze lijst met correcte letters.

    Stap 7: Een willekeurig woord kiezen

const getRandomWord = () => {

};

    Wat gebeurt hier?

    • Math.random() * wordList.length geeft een willekeurig getal tussen 0 en de lengte van onze woordenlijst
    • Math.floor() rondt dit getal naar beneden af, zodat we een geheel getal krijgen
    • We gebruiken dit getal om een woord en hint te selecteren uit onze lijst
    • We slaan het geselecteerde woord op en tonen de hint
    • Ten slotte roepen we resetGame() aan om alles in te stellen

    Stap 8: Het spel starten

    Tot slot starten we het spel en voegen we een gebeurtenis toe voor de "Opnieuw spelen" knop:

    Deze code:

    • Start het spel meteen door getRandomWord() aan te roepen
    • Voegt een klikgebeurtenis toe aan de "Opnieuw spelen" knop die het popup-venster verbergt en een nieuw spel start

    De volledige JavaScript code

    Hier is de volledige code die je in je scripts.js bestand moet plaatsen: 

    // Selecting all elements
const displayText = document.querySelector(".letters");
const hangmanImage = document.querySelector(".drawing__img");
const endGamePopup = document.querySelector(".popup");
const playAgainButton = document.querySelector(".restart-btn");
const keyboardContainer = document.querySelector(".buttons");
const guessesText = document.querySelector(".drawing__score p");

// Initializing the game variables
let selectedWord, correctLetters, wrongGuessCount;
const maxGuessCount = 6;

// Function to display the end screen when the game is over
function showGameOver(isWinner) {
  const modalImage = endGamePopup.querySelector("img");

  if (isWinner) {
    modalImage.src = "./src/images/victory.gif";
    endGamePopup.querySelector("h2").innerText = "Gefeliciteerd!";
    endGamePopup.querySelector(
      "p"
    ).innerText = `Je hebt het woord gevonden: ${selectedWord}`;
  } else {
    modalImage.src = "./src/images/lost.gif";
    endGamePopup.querySelector("h2").innerText = "Helaas!";
    endGamePopup.querySelector(
      "p"
    ).innerText = `Het juiste woord was: ${selectedWord}`;
  }

  endGamePopup.classList.add("show");
}

// Function to start a new game
const resetGame = () => {
  correctLetters = [];
  hangmanImage.src = `./src/images/hangman-0.svg`;
  wrongGuessCount = 0;
  guessesText.innerText = `${wrongGuessCount} / ${maxGuessCount}`;

  // creates the empty letter slots (spliting the word into an array of letters and mapping them to a list item)
  displayText.innerHTML = selectedWord
    .split("")
    .map(() => `<li class="letter"></li>`)
    .join("");

  // enable keyboard buttons
  keyboardContainer
    .querySelectorAll("button")
    .forEach((btn) => (btn.disabled = false));

  // hide the game modal
  endGamePopup.classList.remove("show");
};

//creating a for loop to display our keyboard buttons we use the numbers 97 to 122 since these are the ASCII values for the lowercase letters a-z
for (let i = 97; i <= 122; i++) {
  //creating a button for each letter of the alphabet
  const button = document.createElement("button");
  // converts ASCII/Unicode values to their corresponding characters
  button.innerText = String.fromCharCode(i);
  //adding the button to the keyboard div
  keyboardContainer.appendChild(button);
  //adding an event listener to the button fromcharcode makes sure that we get the correct letter when we click on the button
  button.addEventListener("click", (e) =>
    startGame(e.target, String.fromCharCode(i))
  );
}

//function to handle the game logic when a button on the keyboard is clicked
const startGame = (button, clickedLetter) => {
  // Check if the letter is in the word
  if (selectedWord.includes(clickedLetter)) {
    // Split word into array of letters
    const letters = selectedWord.split("");

    // Loop through each position in the word
    for (let index = 0; index < letters.length; index++) {
      if (letters[index] === clickedLetter) {
        correctLetters.push(letters[index]);
        const letterSlot = displayText.querySelectorAll("li")[index];

        // Update the display
        letterSlot.innerText = letters[index];
        letterSlot.classList.add("guessed");
      }
    }
  } else {
    // Handle wrong guess
    wrongGuessCount++;
    hangmanImage.src = `./src/images/hangman-${wrongGuessCount}.svg`;
  }
  //disable the button after it is clicked
  button.disabled = true;
  //update the guesscount
  guessesText.innerText = `${wrongGuessCount} / ${maxGuessCount}`;

  //check if the game is over
  if (wrongGuessCount === maxGuessCount) {
    showGameOver(false);
  } else if (
    selectedWord.split("").every((letter) => correctLetters.includes(letter))
  ) {
    showGameOver(true);
  }
};

// Function to get a random word from our word-list.js
const getRandomWord = () => {
  // Get random index from the word list
  const randomIndex = Math.floor(Math.random() * wordList.length);
  // Get the word object based of the randomized index
  const wordObject = wordList[randomIndex];

  // Set the current word and hint
  selectedWord = wordObject.word;
  document.querySelector(".clue b").innerText = wordObject.hint;

  // Reset the game
  resetGame();
};

//start the game with a random word
getRandomWord();

//add an event listener to the play again button to reset the game when clicked
playAgainButton.addEventListener("click", () => {
  endGamePopup.classList.remove("show");
  getRandomWord();
});
