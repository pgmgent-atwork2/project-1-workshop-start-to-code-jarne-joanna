    Introductie

    Welkom bij je eerste programmeerproject! In deze tutorial bouw je een compleet Hangman-spel vanaf nul. Zelfs als je nog nooit een regel code hebt geschreven: geen paniek – we leggen alles stap voor stap uit.

    Wat is Hangman? Hangman (Galgje) is een spel waarbij je een verborgen woord moet raden. Je doet dit door letters te proberen. Elke fout zorgt ervoor dat een stukje van de galg wordt getekend. Je wint als je het woord raadt vóór het poppetje compleet is.

    Wat is HTML? HTML betekent HyperText Markup Language. Zie het als het skelet van een webpagina. Met HTML geef je structuur aan je inhoud: titels, paragrafen, knoppen, afbeeldingen… allemaal via HTML-tags zoals <h1> of <p>.

    Wat is CSS? CSS staat voor Cascading Style Sheets. Als HTML het skelet is, dan is CSS de huid, kleding en stijl. CSS bepaalt kleuren, lettertypes, ruimtes, en waar alles staat.

    Wat is JavaScript? JavaScript maakt je pagina interactief. HTML zorgt voor de structuur, CSS voor het uiterlijk, en JavaScript zorgt ervoor dat dingen reageren: klikken op knoppen, controleren of je de juiste letter koos, het tonen van een win- of verliesbericht… allemaal JavaScript.

    Wat heb je nodig?

    Voor we kunnen beginnen, heb je een paar dingen nodig:

    • Een computer (Windows, Mac of Linux)
    • Een webbrowser (Chrome, Firefox, Edge of Safari)
    • Een code-editor – wij raden Visual Studio Code aan
    • 2 tot 3 uur vrije tijd
    • Een beetje geduld en nieuwsgierigheid – programmeren is als puzzels oplossen

    Je hoeft niet alles in één keer te begrijpen. Deze tutorial is gemaakt om je te begeleiden, stap voor stap. Jij kan dit.

    Stap 1: HTML - De structuur van je spel

    Wat is HTML?

    HTML (HyperText Markup Language) is de bouwsteen van elke website. Het is de taal die we gebruiken om de structuur en inhoud van een webpagina te maken.

    Basisstructuur aanmaken

    Laten we beginnen met het maken van een nieuw project:

    1. Maak een nieuwe map voor je project en noem deze "hangman-game"

    2. Open Visual Studio Code en kies "File" → "Open Folder" en selecteer je nieuwe map

    3. Maak een nieuw bestand door te klikken op "File" → "New File" en sla dit op als "index.html"

    De HTML structuur

    Kopieer en plak deze code in je index.html bestand:

    <!DOCTYPE html>
    <html lang="nl">
    <head>
        <meta charset="UTF-8">
        <meta name="viewport" content="width=device-width, initial-scale=1.0">
        <title>Minimalist Hangman</title>
        <link rel="stylesheet" href="./src/css/reset.css">
        <link rel="stylesheet" href="./src/css/main.css">
        <link href="https://fonts.googleapis.com/css2?family=Inter:wght@400;600&display=swap" rel="stylesheet">
    </head>
    <body>
        <div class="app">
            <header class="header">
                <h1>Hangman Game</h1>
                <p>Raad het woord voor het te laat is!</p>
            </header>
    
            <main class="main">
                <!-- Pop-up voor einde spel -->
                <div class="popup">
                    <div class="popup__content">
                        <img src="./src/images/victory.gif" alt="gif">
                        <h2>Wrong answer!</h2>
                        <p></p>
                        <button class="restart-btn">Try again</button>
                    </div>  
                </div>
    
                <!-- Game container -->
                <div class="game">
                    <div class="drawing">
                        <img class="drawing__img" src="./src/images/hangman-0.svg" alt="hangman-img">
                        <div class="drawing__score"><p></p></div>
                    </div>
    
                    <div class="gameplay">
                        <h4 class="clue">Hint: <b></b></h4>
                        <ul class="letters"></ul>
                        <div class="buttons"></div>
                    </div>
                </div>
            </main>
        </div>
    
        <script src="./src/scripts/word-list.js"></script>
        <script src="./src/scripts/scripts.js"></script>
    </body>
    </html>

    Uitleg van de HTML-code

    De basis structuur

    Laten we de belangrijkste delen uitleggen:

    • <!DOCTYPE html> - Dit vertelt de browser dat we HTML5 gebruiken
    • <html lang="nl"> - Het begin van onze HTML, met Nederlands als taal
    • <head>...</head> - Bevat meta-informatie, titel en links naar CSS-bestanden
    • <body>...</body> - Hier komt alles wat zichtbaar is op de webpagina

    De game onderdelen

    Onze game bestaat uit verschillende onderdelen:

    • Header - De titel en subtitel van het spel
    • Popup - Dit wordt getoond als het spel is afgelopen
    • Drawing - Hier komt de hangman tekening
    • Gameplay - Bevat de hint, letters van het te raden woord en toetsenbordknoppen

    Projectstructuur aanmaken

    Nu moeten we enkele mappen maken voor onze bestanden:

    1. Maak een map genaamd "src" in je hoofdmap

    2. Maak binnen de "src" map drie submappen:

      • "css" - voor je stijlbestanden
      • "scripts" - voor je JavaScript bestanden
      • "images" - voor afbeeldingen

    Je projectstructuur zou er nu zo uit moeten zien:

    hangman-game/
    ├── index.html
    └── src/
        ├── css/
        ├── scripts/
        └── images/

    Afbeeldingen toevoegen

    Voor ons spel hebben we afbeeldingen nodig van de verschillende fases van de hangman. Download deze afbeeldingen en plaats ze in de "images" map. (Zelf te maken of downloaden van een website.)

    Nu je de HTML structuur hebt gemaakt, is het tijd om je spel te stylen met CSS!

    Stap 2: CSS - Maak je spel mooi

    Wat is CSS?

    CSS (Cascading Style Sheets) zorgt voor de vormgeving van je webpagina. Met CSS kunnen we kleuren, lettertypen, afstanden en posities bepalen.

    De bestanden maken

    We gaan twee CSS-bestanden maken:

    1. reset.css - Om de standaardstijlen van browsers te verwijderen

      Maak een nieuw bestand in de "css" map en noem het "reset.css"

    2. main.css - Voor onze eigen stijlen

      Maak een nieuw bestand in de "css" map en noem het "main.css"

    Reset CSS

    Kopieer deze code naar je reset.css bestand:

    /* reset.css */
    * {
        margin: 0;
        padding: 0;
        box-sizing: border-box;
    }
    
    html, body {
        height: 100%;
    }
    
    body {
        font-family: 'Inter', sans-serif;
        line-height: 1.6;
    }
    
    button {
        border: none;
        outline: none;
        cursor: pointer;
        font-family: inherit;
    }
    
    ul {
        list-style: none;
    }

    Deze code zorgt ervoor dat alle browsers op dezelfde manier beginnen, wat helpt om verrassingen te voorkomen.

    Uitleg van de CSS-code

    CSS Variabelen

    We gebruiken CSS variabelen voor kleuren die in het hele document worden gebruikt:

    :root {
        --primary-color: #2563eb;
        --success-color: #10b981;
        --danger-color: #ef4444;
        --dark-color: #1f2937;
        --light-color: #f8fafc;
        --gray-color: #9ca3af;
    }

    Dit maakt het gemakkelijk om kleuren aan te passen in het hele document.

    Layout

    We hebben de app gecentreerd en een maximale breedte gegeven:

    .app {
        max-width: 800px;
        margin: 0 auto;
        padding: 2rem 1rem;
    }

    Flexbox

    We gebruiken Flexbox voor de lay-out om elementen gemakkelijk te positioneren:

    .game {
        display: flex;
        flex-direction: column;
        gap: 2rem;
    }
    
    /* Op grotere schermen veranderen we naar naast elkaar */
    @media (min-width: 768px) {
        .game {
            flex-direction: row;
            align-items: center;
        }
    }

    Letters en knoppen

    Voor de letters en toetsenbordknoppen gebruiken we een gestructureerde aanpak:

    .letters {
        display: flex;
        justify-content: center;
        flex-wrap: wrap;
        gap: 0.5rem;
    }
    
    .letter {
        width: 40px;
        height: 40px;
        border-bottom: 2px solid var(--dark-color);
        text-align: center;
    }

    Popup styling

    De popup wordt getoond of verborgen met CSS transitions:

    .popup {
        opacity: 0;
        visibility: hidden;
        transition: all 0.3s ease;
    }
    
    .popup.show {
        opacity: 1;
        visibility: visible;
    }
